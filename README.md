# Ньютонның бірінші заңы — 9-сынып (слайд-зертхана)

Интерактивті слайдтар: анимациялар, стоп-кадр сұрақтары, жазу тақтасы.

## GitHub Pages арқылы ашу

1. github.com сайтында жаңа репозиторий ашыңыз (мысалы, `newton-1-zan`), **Public** таңдаңыз.
2. «Add file → Upload files» басып, осы қалтадағы **index.html** және **.nojekyll** файлдарын салыңыз → «Commit changes».
3. **Settings → Pages** бөліміне өтіңіз. «Source» → **Deploy from a branch**, Branch → **main**, қалта → **/(root)** → **Save**.
4. 1–2 минуттан кейін сілтеме шығады:
   `https://<сіздің-атыңыз>.github.io/newton-1-zan/`

Слайдты осы сілтеме арқылы ашыңыз. github.com ішінде файлдың өзін басқанда тек код көрінеді, анимация жұмыс істемейді.
